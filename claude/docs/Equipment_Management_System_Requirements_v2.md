# 機材管理システム 要件定義書 v2.0

## システム概要

**shin-on 機材管理システム** - 演劇・ミュージカル公演における機材の総合管理システム

### 技術スタック
| 項目 | 技術 |
|------|------|
| フレームワーク | Laravel 12 (PHP 8.4) |
| データベース | MySQL 8.0 |
| 開発環境 | Docker (Laravel Sail) |
| 認証 | LINE WORKS SSO |
| バックアップ | Dropbox OAuth 2.0 |
| フロントエンド | Tailwind CSS v4 + Alpine.js |

### 規模
- 機材数: 約5,000個
- 年間公演数: 約100公演
- ユーザー数: 約30人

---

## 機材管理

### 管理方式
| 方式 | 説明 | 識別子 |
|------|------|--------|
| 個体管理 | 機材個別にシリアル管理 | 新音番号（company_number） |
| 数量管理 | 在庫数量で管理 | なし |

### カテゴリ階層
```
大分類（例：ミキシングコンソール）
└── 中分類（例：デジタルミキサー）
    └── 機材アイテム
```

### 機材ステータス
| ステータス | 色 | 説明 |
|------------|-----|------|
| available | 緑 | 利用可能 |
| reserved | 青 | 予約済み |
| checked_out | 赤 | 出庫中 |
| checked_in | 灰 | 返却済み |
| repair | 橙 | 修理中 |
| maintenance | 黄 | メンテナンス中 |
| lost | 茶 | 紛失 |
| retired | 白 | 廃棄 |

---

## 公演・フェーズ管理

### フェーズ構成例
```
公演: ハムレット
├── 稽古場1（2025/01/10〜01/20）
├── 録音（2025/01/25〜01/26）
├── 稽古場2（2025/02/01〜02/15）
└── 本番（2025/02/20〜03/10）
```

### 期間重複チェック
- 同一機材の使用期間重複を自動検出
- UI・Laravel・DBトリガーの3層防御

## 倉庫・在庫管理

### 倉庫システム
- **基本倉庫（location_id）**: 機材のデフォルト保管場所
- **現在地（now_location_id）**: 現在の保管場所
- **一発返却**: 現在地→基本倉庫への即時返却

### 在庫表示
- 基準日指定での在庫状況表示
- 倉庫別在庫一覧
- カテゴリ別フィルタリング

### Role
| Role | 説明 |
|------|------|
| admin | 管理者（全機能） |
| editor | 編集者（機材編集可） |
| general | 一般（担当公演のみ編集可） |
| viewer | 閲覧者（閲覧のみ） |
