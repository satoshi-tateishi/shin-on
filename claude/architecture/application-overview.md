## 📁 ディレクトリ構造

### 標準Laravel構造
```
app/
├── Console/              # Artisanコマンド
├── Exceptions/           # 例外ハンドラー
├── Http/
│   ├── Controllers/      # コントローラー
│   ├── Middleware/       # ミドルウェア
│   └── Requests/         # フォームリクエスト
├── Models/               # Eloquentモデル
├── Providers/            # サービスプロバイダー
└── Services/             # ビジネスロジック（追加予定）

resources/
├── css/                  # Tailwind CSS
├── js/                   # JavaScript
└── views/                # Bladeテンプレート

database/
├── factories/            # モデルファクトリー
├── migrations/           # データベースマイグレーション
└── seeders/              # シーダー

tests/
├── Feature/              # 統合テスト
└── Unit/                 # 単体テスト
```

### 予定される追加構造
```
app/
├── Services/             # ビジネスロジック層
│   ├── UserService.php
│   └── AuthService.php
├── Repositories/         # データアクセス層（必要時）
├── DTOs/                 # データ転送オブジェクト
├── Enums/                # 列挙型（PHP 8.1+）
└── Traits/               # 再利用可能なトレイト
```

## 📋 機材管理システム仕様

### 機材名の改行対応
**要件**: 機材名フィールドで改行入力を可能にし、各画面で適切に表示する

#### 対応箇所
1. **入力フォーム**
   - 機材登録フォーム: `<input type="text">` → `<textarea>` に変更
   - 機材編集フォーム: `<input type="text">` → `<textarea>` に変更

2. **表示画面**
   - 在庫一覧画面: 改行文字の適切な表示処理
   - 機材一覧画面: 改行文字の適切な表示処理
   - 機材詳細画面: 改行文字の適切な表示処理
   - その他機材名を表示する全画面

#### データベース仕様
- **テーブル**: `equipments`
- **カラム**: `name` VARCHAR(255)
- **制約**: 改行文字を含む文字列の格納に対応済み

#### バリデーション仕様
- **ルール**: `'name' => 'required|string|max:255'`
- **改行対応**: 改行文字を含む文字列の検証に対応済み

#### 表示処理
- **改行表示**: `nl2br()` や `white-space: pre-wrap` を使用
- **レスポンシブ**: 改行を含む長い機材名の適切な折り返し処理
